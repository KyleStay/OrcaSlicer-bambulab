# Local CI

All CI runs locally. Run `./.ci/local.sh` for the full required lane set, or name a lane explicitly. `--list` lists lanes; `--check` checks only the guard/Python syntax, not application coverage. Missing prerequisites/incomplete coverage return 2; command failures propagate. Results and command logs remain under `.ci/results/`.

Default all retains profile, gettext, shellcheck, native configure/build/test, system/custom profile-validator requirements and finally an explicit incomplete marker for the rest of the platform matrix. Individual labelled lanes permit useful local results without claiming all platforms. No shell/locale/profile failure is ignored. `profiles` runs the unchanged Python profile checker. `locale` runs msgfmt --check-format into ignored local output. `build-tests` configures out of source, sets BUILD_TESTS=ON and builds app plus libslic3r_tests/fff_print_tests/slic3rutils_tests/sla_print_tests/libnest2d_tests and runs ctest with --no-tests=error. Provision native dependencies first using the documented platform helpers in AGENTS.md; missing dependencies fail. `profile-validator` needs a preinstalled Linux validator plus a disposable custom-preset fixture tree, supplied as ORCA_PROFILE_VALIDATOR/ORCA_PROFILE_FIXTURE; it never downloads an executable or mutates the source preset tree. Original Ubuntu 22/24 portable/AppImage, Fedora 41 RPM, Windows/MSBuild/WSL2, native macOS arm64/x86_64/universal, Linux bridge/rootfs, test binaries, custom-profile and gettext matrix remains recorded in matrix-inventory.json and archived-workflows. Do not run printer/network mutation probes such as test_moonraker_lane_data.py unattended. Packaging/release/Winget uploads, R2 publication, issue/PR bots, telemetry and auto-commit translation updates are retired external automation; no credentials, network services, administrator installers, user plugin directories or shared system settings are touched by this runner.

## Original coverage

The byte-for-byte original YAML files are inactive archive references, not runnable hosted triggers. `archive-manifest.json` records their source commit, original path and SHA-256; `matrix-inventory.json` retains every original job, runner, condition, matrix, environment and step. GitHub expressions and action wrappers there require local values/tools/artifacts; never execute the archive as a workflow or fetch CI secrets. Existing remote logs/artifacts and retention remain unchanged.

## Publishing this migration

This commit removes every active workflow YAML atomically. A `[skip ci]` commit annotation is an additional push/PR safeguard; it is not a replacement for removing sources. Verify remote default-branch source and runs for the exact pushed commit using read-only API calls. Do not test by dispatching CI.
